# TRACE · Hackathon entry materials

**Project name:** TRACE · X Layer Project Growth Atlas

## Project description

TRACE is an X Layer Project Growth Atlas that helps people discover newly indexed pools and helps builders share public development milestones. Every loaded pool stays visible, including early or incomplete records. Users inspect source fields, transparent thresholds and an eight-NAND gate trace, export a dated evidence snapshot, and compare the two local output bits with a read-only X Layer mainnet circuit call.

Builders can create shareable project cards containing their contract, TapeOut Processor, public GitHub and demo. Opening a card rechecks contract code, official factory registration, reported circuit count and public repository accessibility. This gives builders a simple, reproducible way to showcase their progress.

TRACE Growth Processor was created through the official TapeOut factory on X Layer mainnet (chain ID 196). Circuit #1 has 4 inputs, 2 outputs and 8 NAND gates; it represents discovery entry and public-progress showcase milestones. Two independent RPCs verified the successful tape-out, NFT owner and all 16 truth-table rows; the frontend RPC implementation also matched all 16 outputs.

2. Inspect source observations, four input bits, the eight-NAND trace and two outputs.
3. Show the matching read-only Circuit #1 result and download the evidence snapshot.
4. Create a TRACE builder card with the real Processor and public links; open the share URL to rerun its checks.
